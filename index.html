MJ Plot COS

MJ Plot COS is a personal tool used by one person, its owner, to keep track of documents in their own Google Drive. It is not offered to anyone else.

Privacy policy

With the owner's permission, the tool reads the owner's Google Drive files and Google Docs using read-only access (drive.readonly and documents.readonly). It cannot create, edit, share or delete anything.

What it reads is used only to produce private summaries and to-do lists for the owner. That data stays in the owner's private storage. It is not sold, shared with third parties, or used for advertising.

The owner can revoke access at any time at myaccount.google.com/permissions.

Google user data use complies with the Google API Services User Data Policy, including the Limited Use requirements.
